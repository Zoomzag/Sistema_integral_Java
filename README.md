Este es un sistema integral integral inspirado en el antiguo SII que manidaba el Instituto Tecnológico de Chihuahua Campus II, el cual contaba con características que resultaban de gran administrativo para el personal, docente y el alumnado. El proyecto no está, ya que corresponde a una una migración del modelo original modelo en Django con Python. A de de deo versión esta esta nueva parte con el marco de trabajo Primavera Boot en Java, e incluyer características al proyecto al original, así como nuevos, problemas y soluciones.

El proyecto fue fue detallada enteramente en Java 21 uso la presente y el establecimiento de la instalación hasta la fecha de la frontera, la 3.2.x (o la versión de Spring Boot, leaddo por correspondencia), con junto a las dependencias para una negociación de negociaciones entre: Spring Web, Spring Data JPA, Spring Security, MySQL Driver, Flyway Migration, Lombok, Spring Boot DevTools y Thymeleaf.

El proyecto fue custom en mente una base de datos en MySQL, cualidad cual la información materialidad de gestión cotidianas, escolares, controles, evaluaciones, administración de instalaciones, y comunicación servicios, entre otros.
